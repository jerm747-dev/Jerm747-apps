747 GP custom track art
=======================
Drop finished art in this folder with these exact names and reload the game:
  barrier.png   the armco barrier (the blue/white wall)
  curb.png      the red/white kerbs on corners
(.webp or .jpg also work.) Remove the file to get the built-in look back.

Templates
  barrier-template.png / barrier-guide.png   1024 x 256  = 4 m of wall, 1 m tall
  curb-template.png    / curb-guide.png      512 x 1024  = 1.4 m across, 4 m along
Start from the *-template.png (the current look). The *-guide.png shows the measurements.
Both images repeat along the track, so the matching edges must line up seamlessly.
Don't name your file barrier-template.png - only barrier.png / curb.png are picked up.
